# Tasmociag
Repozytorium zawiera Projekt 2 - zadanie 1 oznaczone jako main.cpp i plik tekstowy CMake oznaczony jako CMakeLists.txt.
Program generuje przedmioty o losowych wagach na taśmociągu, a następnie ładuje je do samochodów.
W programie można zmienić: 
-zakres losowych wag (zmienna: mozliwe_wagi)
-zakres wag maksymalnych samochodów (zmienna: waga_przedmiotu)
-ilość przedmiotów generowanych na taśmociągu (zmienna: il_przedm_na_podajniku)
